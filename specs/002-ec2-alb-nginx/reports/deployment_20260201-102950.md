## Architecture Summary

### Infrastructure Overview

The deployed infrastructure implements a production-ready, highly available web serving platform with the following characteristics:

**Network Architecture**:
- Default VPC in ap-southeast-1 region (vpc-0fb658b91e2113ece)
- 2 availability zones for redundancy (ap-southeast-1a, ap-southeast-1b)
- Public subnets for internet-facing Application Load Balancer
- Security groups implementing least privilege network access

**Compute Layer**:
- 2 × EC2 instances (t3a.micro) running Amazon Linux 2023
- Nginx web server installed via user data script
- Distributed across separate availability zones for fault tolerance
- IAM instance profiles with SSM managed instance core policies
- Encrypted EBS root volumes (8GB GP3)

**Load Balancing**:
- Application Load Balancer (Layer 7) with HTTPS listener
- TLS termination at ALB with self-signed certificate for web.demo.com
- Target group with health checks on HTTP port 80
- Automatic routing to healthy instances only

**Security**:
- HTTPS-only access enforced (no HTTP listener)
- Security groups deny all by default, explicit allow rules only
- TLS 1.3 encryption (ELBSecurityPolicy-TLS13-1-2-2021-06)
- No static credentials in code or state
- Private key managed as sensitive variable in HCP Terraform

   - State locking prevented concurrent modifications

### Challenges Encountered ⚠️

1. **Circular Dependency in Security Groups**
   - **Challenge**: ALB security group needs to reference EC2 security group for egress, but EC2 SG needs ALB SG for ingress
   - **Impact**: Required workaround with separate `aws_security_group_rule` resource
   - **Resolution**: Created security groups first, then added cross-references via standalone rules
   - **Time Lost**: ~15 minutes for research and implementation

2. **Module Limitation for Target Attachments**
   - **Challenge**: ALB module v10.2.0 has limited support for dynamic target group attachments
   - **Impact**: Had to use standalone `aws_lb_target_group_attachment` resources
   - **Resolution**: Set `create_attachment = false` in module, managed attachments separately
   - **Time Lost**: ~10 minutes

3. **Self-Signed Certificate Generation**
   - **Challenge**: No private registry module available for self-signed TLS certificate generation
   - **Impact**: Required direct use of Terraform TLS provider resources
   - **Resolution**: Created tls_private_key, tls_self_signed_cert, and aws_acm_certificate resources manually
   - **Time Lost**: ~20 minutes for research and testing

4. **User Data Script Testing**
   - **Challenge**: Nginx installation in user data cannot be easily tested before deployment
   - **Impact**: Required full infrastructure deployment to validate user data script
   - **Resolution**: Carefully reviewed script syntax and tested manually post-deployment
   - **Time Lost**: ~5 minutes for additional validation

5. **Git Pager in CI/CD**
   - **Challenge**: Git commands using pager caused interactive prompts blocking automation
   - **Impact**: Required manual intervention to quit pager
   - **Resolution**: Added `--no-pager` flag to all git commands
   - **Time Lost**: ~5 minutes
