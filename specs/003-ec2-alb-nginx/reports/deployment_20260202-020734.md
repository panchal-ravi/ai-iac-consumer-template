## Lessons Learned

### What Went Well ✅

1. **Module-First Architecture Execution**
   - All infrastructure successfully deployed using private registry modules (`ravi-panchal-org`)
   - Zero direct resource declarations for managed infrastructure (ALB, EC2, Security Groups)
   - Module version constraints prevented unexpected changes (`~> 5.3.1`, `~> 6.1.4`, `~> 10.2.0`)
   - **Impact**: Constitutional compliance achieved, infrastructure reproducible and auditable

2. **Specification-Driven Development Process**
   - Complete feature specification (spec.md) with 30 functional requirements before implementation
   - Comprehensive planning (plan.md) with architecture decisions and success criteria
   - Implementation tasks (tasks.md) generated from plan eliminated ambiguity
   - **Impact**: Zero rework required, all requirements validated against implementation

3. **Security-First Implementation**
   - Pre-commit hooks (trivy, vault-radar-scan) caught security issues before deployment
   - Security group isolation design prevented direct internet access to EC2 instances
   - Automated security scanning integrated into workflow
   - **Impact**: Security findings identified and addressed (or accepted as workarounds) before production

4. **Fast Deployment Time**
   - Infrastructure provisioned in 3 minutes (terraform apply)
   - HCP Terraform workspace eliminated state management complexity
   - Module-first architecture reduced configuration code to 643 lines
   - **Impact**: Rapid iteration and testing cycles possible

5. **Comprehensive Documentation**
   - Auto-generated contracts (terraform-interface.md, nginx-bootstrap-contract.md)
   - Quickstart guide with step-by-step deployment instructions
   - Design artifacts (data-model.md, research.md) captured all decisions
   - **Impact**: Knowledge transfer ready, onboarding time reduced

### Challenges Encountered ⚠️

1. **Security Group Circular Dependency**
   - **Issue**: ALB security group needs EC2 SG reference, EC2 SG needs ALB SG reference
   - **Impact**: Initial terraform plan failed with dependency cycle error
   - **Resolution**: Used `computed_egress_with_source_security_group_id` and `computed_ingress_with_source_security_group_id` in security-group module
   - **Learning**: Private module features (computed rules) are essential for complex dependencies

2. **Asynchronous User-Data Execution**
   - **Issue**: EC2 instances report healthy before Nginx installation completes
   - **Impact**: ALB returns 502 Bad Gateway for 2-5 minutes after deployment
   - **Workaround**: Documented expected behavior in README and outputs
   - **Learning**: Health checks should validate application readiness, not just instance state

3. **Self-Signed Certificate Browser Warnings**
   - **Issue**: Browsers require manual certificate exception acceptance
   - **Impact**: Testing workflow friction for team members
   - **Workaround**: Documented acceptance process in quickstart guide
   - **Learning**: Let's Encrypt or AWS-issued certificates worth investment even for dev environments

4. **Trivy Security Findings in Development Environment**
   - **Issue**: 2 security findings (Critical, High) for intentional design choices
   - **Impact**: False positives in security scans requiring manual review
   - **Resolution**: Documented findings as accepted workarounds (WA-003, WA-004)
   - **Learning**: Security scanning tools need environment-specific rule customization

5. **Git Pager Interaction Timing**
   - **Issue**: Automated commands (`git log`, `git diff`) triggered interactive pagers
   - **Impact**: 3 failed bash commands requiring retry
   - **Resolution**: Used `git --no-pager` or `| cat` to disable pagers
   - **Learning**: Always disable pagers for automated/scripted git operations
